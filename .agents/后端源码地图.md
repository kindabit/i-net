本文档是后端源码地图，收录后端源码文件与业务功能的对应关系，供人与大语言模型双向检索（按文件名查功能、按功能名查文件）。

收录规则：
- 收录：文件名、业务能力名、稳定契约名（类型名、ErrorCode 系列名、表名等）、模块级联动关系
- 排除：代码符号名（函数名、变量名、字段名、参数名）、行为枚举（逐条罗列某功能的每种行为或规则）、实现细节（判断逻辑、算法步骤、字节布局、错误处理分支）
- 收录范围：src-tauri/src/ 下的源码文件；测试代码集中在"测试时"章节统一说明
- 每个后端源码文件在三份地图（本文档、前端源码地图、概念地图）中恰好出现一次
- 描述必须使用概念地图（概念地图.md）定义的术语；概念级内容不重述，用"见概念地图·概念名"引用
- 章节内条目按模块生命周期或调用链顺序排列；高度同构的 command/service/dao 文件组按目录级条目收录，目录条目内以"文件名（功能）"形式点名各操作文件

## 测试时

## 运行时

### 入口

- main.rs：进程入口
- lib.rs：插件注册、command 注册、setup（初始化数据目录与日志、设置全局路径状态、初始化 preference 与 metadata 并设置全局连接状态）、退出生命周期（保存 preference、metadata 与处于打开状态的用户数据库）
- state.rs：全局路径状态（Path 类型），启动时写入、各处读取；含"导出目标路径必须位于数据目录之外"的校验
- argv.rs：命令行参数解析

### 通用业务模块

common.rs 是跨模块耦合的集中点

- connection.rs 与 connection/service/：数据库文件的打开与保存（明文与加密变体），被各专项业务模块使用；数据版本经其透明渗透（见概念地图·数据版本）
- data_version.rs 与 data_version/：数据版本的建表、写入与校验
- variable.rs 与 variable/：键值变量读写，被 registry 等模块复用

### 专项业务模块

business.rs 是模块清单；各专项业务模块之间无源码间依赖，保持低耦合

- app_info.rs：向关于对话框提供编译期确定的应用元数据
- preference.rs 与 preference/：用户偏好——state.rs 全局连接状态；service/ 初始化、保存、读写；command/ 对应接口（见概念地图·主题与偏好）
- metadata.rs 与 metadata/：用户数据库元数据——state.rs 全局连接状态；entity/ 实体；service/ 初始化、保存、注册、列表、归档、物理删除；dao.rs；command/ 对应接口（见概念地图·用户数据库与元数据）
- backup.rs 与 backup/：数据目录级备份与还原——format.rs 备份包格式、codec.rs 包体编解码、progress.rs 进度提示、service/ 打包、解包、还原探测、体积预测；command/ 对应接口（见概念地图·备份包）
- reclaim.rs 与 reclaim/：内存刷新——command/ 下 preference、metadata、user_database 三个接口（见概念地图·内存刷新）
- fatal_exit.rs：受控崩溃接口（见概念地图·受控崩溃）
- clipboard.rs 与 clipboard/：剪贴板清除（command/clear.rs）

### 用户数据库业务模块

user_database.rs 下的子业务模块

- state.rs：用户数据库全局状态（连接 + 元数据 + 密钥，见概念地图·用户数据库与元数据）
- entity.rs 与 entity/：实体类型；含根画布名称常量、画布宇宙视口特殊 canvas_id、日志 Action 与 NodeFieldChange 类型
- registry/：注册表键值读写（最后场景经此持久化，见概念地图·最后场景）
- lifecycle/：生命周期——initialize.rs 创建目录结构与数据库文件、建表（与各子业务模块交叉）并设置状态；save.rs、close.rs；command/ 对应接口
- canvas/：画布——service/ 初始化（建表并插入根画布）、新建、移动（move_canvas.rs 单个移动、move_canvases.rs 批量移动）、恢复、重命名、逻辑删除、物理删除、色彩列表（color_list.rs）与设置（set_color.rs）；vo.rs；dao.rs；command/ 对应接口；response/ 色彩条目（根画布保护与级联语义见概念地图·画布宇宙与画布、级联坍塌）
- viewport/：视口初始化与读写（见概念地图·视口）
- dictionary/：字典初始化、全量列表、全量覆盖写（见概念地图·字典）
- attachment/：附件——service/ 初始化、导入、导出、获取附件元数据、顺序调整、列表与孤儿文件列表、逻辑删除、恢复、物理删除、删除孤儿文件、明文加载、文件更新；vo.rs；dao.rs；command/ 对应接口（压缩 guard 与孤儿文件见概念地图·附件与孤儿文件、压缩 guard）
- template/：模板——service/ 初始化、新建、从节点创建、重命名、物理删除、列表、字段读写、导入导出；vo.rs；dao.rs；command/ 对应接口（见概念地图·模板与模板字段）
- node/：节点——service/ 初始化、新建、移动（move_node.rs 单个移动、move_nodes.rs 批量移动）、恢复、列表（影子沿产生边链级联合并根本体展示数据）、修改、复制、逻辑删除、物理删除、关键词搜索（影子节点不参与）、色彩列表（color_list.rs）与设置（set_color.rs）、批量跨画布迁移（relocate_nodes.rs），以及影子机制三文件 shadow_direction.rs（影子方向推导）、resolve_root.rs（根本体解析）、shadow_disconnected.rs（断连收集）；vo.rs；response/；dao.rs；command/ 对应接口（影子机制与断连收集见概念地图·影子节点、影子断连收集、级联坍塌）
- node_field/：节点字段——service/ 初始化；读写（字段类型与值对后端不透明，仅做数据完整性校验、加解密、全量覆盖、变更 diff 生成日志，见概念地图·节点字段与字段类型系统、日志）
- edge/：边——service/ 初始化、新建（create.rs 同向已有边更新连接桩、反向已有边删旧建新）、删除、更新、列表；dao.rs；command/ 对应接口（连接合法性矩阵与影子坍塌见概念地图·影子节点、级联坍塌）
- export/：导出——service/ 导出与后端国际化；command/ 对应接口
- log/：日志——service/ 新增、初始化、分页列表；response/ 分页响应；dao.rs；command/ 对应接口（见概念地图·日志）

### 加解密模块

- security.rs 与 security/aes.rs：AES 加解密（见概念地图·加密与密钥）

### 工具模块

util.rs 下的工具

- time_util.rs：时间工具
- preprocess_util.rs：command 入参预处理（如密码预处理）
- file_system_util.rs：文件系统工具
- compress/：压缩层——guard.rs 压缩/解压门卫、route.rs 分拣路由、execute.rs 执行路由、engine.rs 引擎封装、param.rs 压缩参数（CompressParam）、codec/ 各编码器（brotli_codec.rs、lzma_codec.rs、flac_codec.rs、zstd_codec.rs）（见概念地图·压缩 guard）

### 错误码模块

- error_code.rs：ErrorCode 定义；DataCorruption 系列表示不变量破坏（见概念地图·受控崩溃）；部分错误码限定在特定模块内使用
