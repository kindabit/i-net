本文档以功能为出发点，用于协助人类理解后端功能以及功能之间的联系。

# 基座

不承担具体业务功能的底层技术框架。

- 国际化（ i18n/index.ts ）
    - Vue 插件挂载
    - t 、 te 、 d 等功能函数
    - 当前语言、获取支持的语言列表、设置语言
- snackbar （ composables/use-snackbar.ts + components/AppSnackbarQueue.vue ）
    - 普通消息文本
    - ErrorCode 错误文本（和 error-code 模块耦合）
- 错误码 ErrorCode （ error-code.ts ）
    - 判断一个对象是否是特定变体的 ErrorCode
- 用户偏好（ preference.ts ）
    - 加载偏好，应用初始化时加载
    - 保存偏好
- 节点尺寸常量（ node-size.ts ）
    - 数据节点固定宽高（ px 数值为唯一事实来源，rem 形式与半宽半高由其派生）
    - 画布宇宙节点兜底尺寸（画布节点为内容自适应尺寸，仅供自动布局兜底）
- vuetify （ vuetify.ts ）
    - 将自定义主题接入 vuetify 的系统内部
- 字典状态管理（ dictionary/index.ts ）
    - 管理前端字典数据的唯一事实来源
- 字段类型系统以及依赖该系统的功能
    - 字段类型的定义（ field-types 目录）
        - Schema JSON （定义于项目根目录 schemas/field-types.json 归类于前端）
        - Schema 类型定义（ schema-types.ts ）
        - 相关工具函数（ index.ts ）
    - 字段列表编辑逻辑（ composables/use-field-list.ts ）节点字段与模板字段共用
        - withValues 参数区分值编辑模式（节点）与模板（纯结构）模式
        - 增删行、拖拽排序
        - 从 NodeFieldVO 列表装入 / 从 TemplateFieldVO 列表装入
        - 导出为 NodeFieldVO 列表 / 导出为 TemplateFieldVO 列表
        - 校验、脏状态判断（与初始快照对比）
    - 字段定义行（ components/FieldDefinitionRow.vue ）
        - 字段名、字段类型
        - 不同类型有不同类型配置选项
        - 绑定字典
        - 拖拽
        - 值编辑器插槽（根据字段类型自动选择）
    - 值编辑器组件库（ components/field-editors/ ）
        - 总封装（ FieldValueEditor.vue ）根据字段类型选择合适的具体组件
        - 具体组件
            - 日期（年月日时分秒）
            - 日期范围（年月日时分秒）
            - 文本（邮箱地址、数字、密码、单行文本和多行文本等）
                - 密码生成器对话框

# 全局功能

此类功能的入口位于 App.vue ，任何页面均可访问。

- 国际化（国际化基座功能在业务层的延申）
    - 初始化（ main.ts ）
    - 语言切换（ App.vue ）
- 主题（ themes/index.ts ）
    - 初始化（ main.ts ）
    - 主题切换（ App.vue ）
    - 当前主题（ App.vue 用于高亮主题下拉菜单）（ ThemeEditDialog.vue 用于充当默认主题数据）
    - 主题列表（ App.vue 主题下拉菜单的内容）（ ThemeManagerDialog.vue 主题列表）
    - 主题是否存在（ ThemeEditDialog.vue 保存时校验名称是否重复）
    - 获取主题定义（ ThemeEditDialog.vue 在使用当前主题作为默认主题数据时，用于获取当前主题的数据）
    - 保存自定义主题（ ThemeEditDialog.vue ）
    - 删除自定义主题（ ThemeManagerDialog.vue ）
    - 导出自定义主题（ ThemeManagerDialog.vue ）
    - 导入自定义主题（ ThemeImportDialog.vue ）

# 打开用户数据库之前

此类功能的入口位于 Home.vue 页面。

- 注册和打开数据库（ Home.vue ）
    - 自动恢复上一次关闭数据库时的场景（最后场景）（没有或不适用则默认进入画布宇宙页面）
- 归档管理（ ArchiveManagementDialog.vue ）
    - 归档和解除归档
    - 物理删除数据库（ DeleteDatabaseDialog.vue ）
- 数据目录级备份与还原（ Home.vue 右下角，备份图标 / 还原图标）

# 打开用户数据库之后

此类功能的入口分散在 DatabaseView.vue 和 CanvasUniverseView.vue 文件中。

## 基础支撑功能（ DatabaseView.vue ）

- 右下角
    - 导出数据库
    - 保存并退出数据库
    - 查看日志
- 监听/拦截窗口关闭事件
- 监听路由路径，保存“最后场景”
- 顶部工具栏（ Topbar.vue ）
    - 面包屑导航（ CanvasBreadcrumb.vue ）
        - 进入画布宇宙页面
        - 进入其它父级画布
        - 跨画布迁移落点高亮
    - 全局搜索（ GlobalSearch.vue ）

## 画布宇宙页面（ CanvasUniverseView.vue ）

用户打开数据库后，默认进入画布宇宙页面，画布宇宙自身也是一个画布，其中每个节点都是一个子画布，边表示画布之间的从属关系。

- 页面初始化
    - 加载画布节点和边（边：todo）
    - 加载相机/视口
- 画布交互
    - 节点
        - 拖拽移动
        - 左键拖动空白处框选，框选后拖动任一选中节点批量移动
        - 重命名按钮（根画布除外；根画布名称固定显示为本地化"根画布"文案）
        - 逻辑删除按钮
        - 自定义颜色
        - Backspace 不删除选中节点（已禁用 vue-flow deleteKeyCode）
        - 双击进入画布
    - 视口
        - 相机/视口移动（右键/中键拖动）、缩放
- 左上角悬浮菜单
    - 回收站
        - 恢复节点
        - 物理删除节点
        - 清空回收站
    - 自动布局

## 画布页面（ CanvasView.vue ）

用户在双击画布宇宙中的某个画布节点后可以进入该画布节点所表示的画布，这个画布中的节点表示敏感数据，边表示敏感数据之间的关系。

- 页面初始化
    - 加载节点（未逻辑删除的节点）、边、回收站（已逻辑删除的节点）
    - 加载相机/视口
    - 加载画布列表，用于渲染 breadcrumb
- 画布交互
    - 节点
        - 拖拽移动（节点移动和迁移系统： composables/use-node-move-and-relocate.ts 状态机驱动）
        - 按住 Alt 拖拽跨画布迁移（落点：画布节点/影子节点/面包屑祖先片段；Alt 按下时禁止画布边缘自动滚动；迁移成功后失焦淡出消失—— composables/use-relocate-animation.ts ）
        - 左键拖动空白处框选，框选后拖动任一选中节点批量移动
        - 逻辑删除按钮
        - Backspace 不删除选中节点或边（已禁用 vue-flow deleteKeyCode）
        - 编辑节点
        - 复制节点（相当于使用模板创建新节点）
        - 影子节点（一个只读的，指向父画布内某个节点的虚拟节点，其生命周期由边控制；点击虚拟边快捷跳转至父画布并定位原始节点）
        - 附件
            - 导入、导出、拖拽调整顺序
            - 附件列表、回收站列表、孤儿文件列表
            - 逻辑删除、物理删除、恢复
            - 预览
                - 预览对话框
                - 导出
                - 图片、视频、音频预览
                - onlyoffice 文档预览（ docx 、 xlsx 、 pptx 和 pdf ）
                - 文本编辑器
        - 自定义颜色
        - 画布节点
            - 双击进入画布
    - 边
        - 自定义的边渲染逻辑（ CustomEdge.vue ）
            - 两段贝塞尔曲线
            - 两段曲线中间有缺口用来容纳边的标题
        - 在节点的 handle 之间拖拽连接建立新的边
        - 右键菜单
            - 删除边
            - 编辑边数据
                - 标题
                - 详情
    - 视口
        - 相机/视口移动（右键/中键拖动）、缩放
    - 左上角悬浮菜单
        - 新建节点/模板列表面板
            - 模板管理
                - 模板导入和导出
            - 拖拽创建普通节点或画布节点
        - 字典管理（ DictionaryManagerDialog.vue 树形字典编辑+全量覆盖写）
        - 回收站
            - 恢复节点
            - 物理删除节点
            - 清空回收站
        - 自动布局
- 其它
    - 模板管理对话框（ TemplateManagerDialog.vue ）模板新建/重命名/物理删除/编辑字段（复用 use-field-list 与值编辑器组件库）
    - 日志对话框的字段变更渲染（ LogDialog.vue ）NodeFieldsModify 日志展示逐字段 Added/Modified/Removed
