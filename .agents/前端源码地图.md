本文档是前端源码地图，收录前端源码文件与业务功能的对应关系，供人与大语言模型双向检索（按文件名查功能、按功能名查文件）。

收录规则：
- 收录：文件名、业务能力名、稳定契约名（类型名、ErrorCode 系列名等）、模块级联动关系
- 排除：代码符号名（函数名、变量名、字段名、参数名）、行为枚举（逐条罗列某功能的每种行为或规则）、实现细节（判断逻辑、渲染细节、布局数值、像素约定）
- 收录范围：src/ 目录下的源码文件；测试文件与纯类型声明文件（.d.ts）不收录
- 每个前端源码文件在三份地图（本文档、后端源码地图、概念地图）中恰好出现一次；被多个章节使用的文件归入"基座"章节
- 描述必须使用概念地图（概念地图.md）定义的术语；概念级内容不重述，用"见概念地图·概念名"引用
- 每个条目一行；章节内条目按页面生命周期或调用链顺序排列；文件名无歧义时写裸文件名，有歧义时写最短无歧义相对路径

## 基座

- main.ts：应用入口
- router/index.ts：路由
- api.ts 与 api-types.ts：后端 command 的 TypeScript 封装与传输类型定义（前后端契约层，见概念地图·command 与 ErrorCode、传输类型（VO））
- i18n/index.ts：国际化

- error-code.ts：ErrorCode 变体判断

- use-fatal-error.ts 与 FatalErrorDialog.vue：受控崩溃（见概念地图·受控崩溃）
- node-size.ts：节点尺寸常量
- dictionary/index.ts：字典状态管理（见概念地图·字典）

- NodeField.vue：节点字段行（字段名双击编辑、字段类型、字段值与齿轮悬浮面板中的字典绑定，拖拽手柄纵跨字段名行与字段值行）

- components/field-editors/PasswordGeneratorDialog.vue：密码生成器对话框
- ConfirmDialog.vue：通用确认对话框
- NameInputDialog.vue：通用名称输入对话框
- PasswordField.vue：密码输入框（带可见性切换图标）
- TreeSelect.vue：树形选择器
- use-viewport.ts：视口持久化（见概念地图·视口）
- use-auto-layout.ts：自动布局适配层（视图与布局算法之间的中间层）
- utils/radial-layout.ts：自动布局算法的编排门面（管线编排入口；radial 为历史命名，现算法与径向无关）
- utils/layout/compose.ts、components.ts、component-layout.ts、collision.ts、anchor.ts、sanitize.ts、orientation.ts、layering.ts、types.ts、utils.ts：自动布局管线的各阶段实现
