## 数据模型

### 用户数据库与元数据

定义：用户数据库是存储敏感数据的主存储单元，由 sqlite 文件与附件目录组成；元数据数据库登记全部用户数据库的名称、归档状态等概要信息；偏好数据库存储用户偏好设置。三者的初始化时机不同：程序启动时初始化偏好与元数据，打开用户数据库时初始化用户数据库。
联动：打开用户数据库 → 载入连接、元数据与密钥至全局状态；关闭用户数据库 → 清空全局状态
实现：后端 business/user_database/state、business/metadata、business/preference；前端 Home.vue、DatabaseView.vue

### 画布宇宙与画布

定义：画布宇宙自身是一个特殊画布，其中每个节点是一个子画布，边表示画布之间的从属关系；所有画布通过父子关系形成树形结构，根画布名称固定为本地化"根画布"文案。
不变量：根画布不可删除
实现：后端 business/user_database/canvas；前端 CanvasUniverseView.vue

### 画布节点

定义：画布节点是画布宇宙中把画布呈现为节点的形态，一个画布节点对应一个画布实体，在画布宇宙视图中显示画布名称与图标。
不变量：根画布对应的画布节点不可删除
联动：重命名画布 → 其画布节点显示名称同步更新
实现：前端 CanvasUniverseView.vue、CanvasNode.vue；颜色契约见 node-colors 的 CanvasNode* 类型

### 数据节点与画布数据节点

定义：数据节点承载敏感数据，由字段与附件组成；画布数据节点引用一个子画布，其标题与其引用画布的名称始终保持一致。
联动：重命名画布 → 引用该画布的画布数据节点标题同步更新
实现：后端 business/user_database/node；前端 CanvasView.vue

### 标签与书签

定义：标签是数据节点的自由文本标记，一个节点可携带多个标签、同一标签可挂在多个节点上（多对多关联，node_tag 表）；书签是数据节点的布尔收藏标记。标签与书签只归属于真实节点，影子节点不接受这两类操作，其书签展示状态取自本体节点；标签参与全局搜索，关联至少一个未删除节点的标签（活跃标签）以标签云形态展示。
联动：节点物理删除 → 其标签关联随外键级联清理；节点逻辑删除 → 标签关联保留，但该节点不计入活跃标签与书签列表；标签集合或书签状态变更 → 写入操作日志
实现：后端 business/user_database/node_tag 与 node 的书签相关接口；前端 EditNodeDialog.vue、TagCloudPanel.vue、NodeGroupListDialog.vue

### 边

定义：边表示节点间的依赖关系，含义为"目标依赖源"，可携带标题与详情；连接的合法性受节点类型与影子方向约束（决策表见"影子节点"概念）。
不变量：同画布内边不可成环；同向已有边时仅更新连接桩；反向已有边时执行删旧建新替换
实现：后端 business/user_database/edge；前端 CanvasView.vue CustomEdge.vue

### 影子节点

定义：影子节点是因边存在而存在的只读虚拟节点，引用产生它的边而非节点；分入向影子（数据节点的影子，只能作连线的源）与出向影子（画布数据节点的影子，只能作连线的目标）；可嵌套成影子链。展示数据从本体节点拉取，自有数据仅位置与产生边引用。
约定：产生影子节点的边简称“产生边”，全称“影子产生边”；仅在缺少影子节点上下文时使用全称；从影子节点沿产生边逐层向上指向根本体节点的单条引用结构称“影子链”，强调沿产生边行进时称“产生边链”。
不变量：影子方向必然可推导（由产生边源端是否为画布数据节点决定）；影子的邻居必然非影子；任何不一致返回 DataCorruption 系列错误
联动：边删除 → 其产生的影子级联删除 → 影子子树沿外键递归坍塌（见"级联坍塌"概念）；删除影子节点等价于删除产生它的边
实现：后端 business/user_database/shadow；前端 CanvasView.vue

|节点相连作用关系|数据节点（目标）|画布数据节点（目标）|数据节点的影子节点（目标）| 画布数据节点的影子节点（目标）|
|-|-|-|-|-|
|数据节点（源）|无级联影响（含义为“目标依赖源”）|在目标画布创建源数据节点的影子节点（含义为“目标画布中的节点可能需要依赖该源数据节点”）|非法连接（数据节点的影子节点现在只能是入向影子节点，无法作为目标）|向上查找目标影子节点的本体画布，在本体画布创建源数据节点的影子节点（含义为“目标节点的本体画布中的节点可能需要依赖该源数据节点”）|
|画布数据节点（源）|非法连接（见备注1）|在源画布数据节点创建目标画布数据节点的影子节点（含义为“目标画布中的节点可能需要依赖源画布中的节点，因此需要在源画布中创建目标画布的影子节点，以便所需依赖项进一步在目标画布中建立影子节点”）|非法连接（数据节点的影子节点现在只能是入向影子节点，无法作为目标）|向上查找目标影子节点的本体画布，在源画布中创建指向目标本体画布的影子节点（含义类似“画布数据节点（源） -> 画布数据节点（目标）”，但是多一层“目标画布中的节点可能需要依赖源当前画布的子画布中的节点”的含义）|
|数据节点的影子节点（源）|无级联影响（含义为“目标依赖源影子节点的本体”）|在目标画布数据节点创建影子节点的影子节点（含义为“目标画布中的节点可能需要依赖源影子节点所指的数据节点”）|非法连接（数据节点的影子节点现在只能是入向影子节点，无法作为目标）|非法连接（目标的本体或者上级影子节点直接或间接地存在于父画布中，源的本体或者上级影子节点也直接或间接地存在于父画布中，如果两者需要连接，应该直接在父画布中连接，而不是先接入子画布再连接）|
|画布数据节点的影子节点（源）|非法连接（画布数据节点的影子节点现在只能是出向影子节点，无法作为源）|非法连接（画布数据节点的影子节点现在只能是出向影子节点，无法作为源）|非法连接中的非法连接|非法连接（画布数据节点的影子节点现在只能是出向影子节点，无法作为源）|

备注1：这意味着目标数据节点需要依赖源画布中的节点。我们不允许在源画布中建立目标数据节点的影子节点，因为这可能会导致目标数据节点的依赖项散落在各个不同的画布中，而我们希望依赖项能够集中显示在目标节点的周围，从而避免用户需要一个画布一个画布地查看依赖情况。如果遇到这种需要依赖子画布中的节点的情况，应该先新建一个子画布，然后将目标数据节点放进新的子画布中，再将源画布数据节点和新的子画布数据节点相连，这样源画布中就会出现新的子画布的影子节点，然后再在源画布中将目标数据节点需要依赖的源数据节点与新的子画布的影子节点相连，这样新的子画布中就会出现所需源数据节点的影子节点，最后再将源数据节点的影子节点与依赖它的目标节点相连。

### 模板与模板字段

定义：模板是可复用的字段结构定义，模板字段为纯结构（无值）；复制节点相当于使用模板创建新节点。
实现：后端 business/user_database/template；前端 TemplateManagerDialog.vue、use-template-field-list.ts

### 节点字段与字段类型系统

定义：字段类型是前端侧的展示与编辑元数据，类型目录内化为前端常量（key 形如 "valueKind:subtype"），后端对字段类型与字段值内容完全无感，仅提供不透明读写。字段值为不透明字符串：string 与 decimal 为内容本身；instant 系列为时间格式化字符串加时区后缀（如 "2026-01-01 22:59:59.444|+8"），时间部分按 tz 后缀所表示的时区解释，编辑展示时转换为本地时间、写入时以本地时间与本地时区后缀合成，非法值（含时区后缀缺失或非法）在编辑时不触发受控崩溃，由前端校验在保存时拦截；时间部分的格式即精度，instant-range 为 "start ~ end|tz" 形式。日志与导出直接展示值原文，不做解析。
不变量：字段值明文恒为 UTF-8 字符串；解密成功但明文非 UTF-8 视为数据损坏（DataCorruption 系列，见受控崩溃）
实现：前端 field-types 目录、use-node-field-list.ts、NodeField.vue 与 TemplateField.vue、components/field-editors 目录；后端 node_field、template（仅透传读写，字段值加解密见加密与密钥）

### 字典

定义：字典是树形结构的数据，供字段绑定；采用全量覆盖写策略。
联动：全量覆盖写字典 → 关联的模板字段与节点字段的悬空字典引用被置空
实现：后端 business/user_database/dictionary；前端 DictionaryManagerDialog.vue、dictionary/index.ts

### 附件与孤儿文件

定义：附件元数据存数据库、二进制文件存附件目录；孤儿文件指存在于附件目录但无对应元数据的文件。附件明文在加密前经过压缩 guard 处理。
实现：后端 business/user_database/attachment；前端 views/DatabaseComponents/attachment 目录

### 坐标系

定义：系统内坐标分为屏幕坐标系与画布坐标系两类。屏幕坐标以窗口（视口）左上角为原点、以屏幕像素为单位，描述元素在窗口内的位置；画布坐标以 vue-flow 画布原点为原点，描述元素在画布内的位置，画布宇宙视图与画布视图中的元素同属画布坐标系（二者均由 vue-flow 渲染）。
约定：坐标分绝对与相对；未加限定时默认为绝对画布坐标；屏幕坐标须写明"屏幕坐标"；相对坐标须写明"相对坐标"并指明参照物（如"相对坐标（相对于分量中心）"）；相对屏幕坐标须写明"相对屏幕坐标"。
实现：屏幕坐标来自 clientX/clientY 与 getBoundingClientRect；画布坐标与屏幕坐标的换算由 vue-flow 提供（screenToFlowCoordinate 等）；视口持久化见概念地图·视口

### 视口

定义：相机/视口位置按画布持久化存储，记录视口坐标（屏幕坐标：画布原点相对视口中心的偏移）与缩放比例，视口中心画布坐标 = (-x / zoom, -y / zoom)；画布宇宙的视口使用特殊 canvas_id 区分。
实现：后端 business/user_database/viewport；前端 CanvasView.vue、CanvasUniverseView.vue

### 日志

定义：操作以 Action 类型描述，写入时拆分为 Log 记录入库（行为名明文、数据载荷加密）；分页查询时解密并重组为 Action 返回。查询支持按行为名与时间等明文字段过滤，也支持按数据载荷内容搜索（载荷加密，关键词搜索需先解密后匹配）。NodeFieldChange 类型记录节点字段级变化。
实现：后端 business/user_database/log；前端 LogDialog.vue、LogActionContent.vue

### 数据迁移（KeePass 2.0 导入）

定义：从 KeePass 2.0 数据库文件（.kdbx）导入数据的功能：前端读取文件字节并在前端解密解析，按用户在导入对话框中选择的方式组织数据，KeePass 回收站 group 及其内容不导入，字段名随导入语言由前端渲染（见概念地图·节点字段与字段类型系统）。导入方式有两种：导入单个画布时，将 KeePass 根 group 转换为表示数据库本身的根节点，其余 group 与数据条目按隶属关系转换为后代节点（树形布局坐标由前端计算，父左子右），父子关系以从父节点指向子节点的边表达；按分组生成多个画布时，每个 group 转换为一张画布（含根 group：根 group 画布挂到根画布成为其子画布，子 group 画布挂到父 group 画布，以此类推），group 的数据条目与引用子 group 画布的画布数据节点以矩阵布局平铺在画布内，整棵新画布树在画布宇宙中按 group 层级以树形布局呈现（两条路线的布局坐标均由前端计算，多画布路线的新画布树根位置经环形搜索避让现存画布）。后端提供对应的两个聚合导入接口，只接受前端已构造好的数据：单画布接口接受节点与边数据，在根画布创建以文件名命名的画布与画布数据节点并批量写入节点、字段与边；多画布接口接受画布列表（含各画布的宇宙坐标、层级下标与画布内矩阵坐标），在根画布下批量创建整棵画布子树并写入各画布的数据节点、字段与画布数据节点（字段加密见加密与密钥），两条路线的全部写库操作均聚合为一条日志条目（见概念地图·日志）。
实现：后端 business/user_database/migration；前端 migration/keepass2.ts、KeePass2Import.vue、DatabaseView.vue

## 画布编辑语义

### 节点复制粘贴

定义：节点复制粘贴是画布视图内的节点创建交互，复制时把选中的数据节点以节点 id 与坐标快照写入应用内存剪贴板（不读写系统剪贴板），粘贴时按快照在目标画布逐个创建副本；剪贴板为跨画布共享的模块级状态，粘贴的目标画布可与复制来源画布不同。
约定：复制只针对数据节点，影子节点与画布数据节点不参与；快捷键为 Ctrl/Cmd+C 与 Ctrl/Cmd+V，仅在无对话框、菜单与画布内悬浮面板打开且焦点不在输入控件内时生效；粘贴落点（画布坐标）取最近一次指针位置（屏幕坐标），指针不在画布容器内时回退到容器中心，多节点按复制时的相对布局整体平移使包围盒中心落在落点并吸附到网格，粘贴完成后选中新副本。
联动：粘贴 → 副本归属目标画布而非复制来源画布；剪贴板中的源节点已被删除 → 跳过该节点并继续粘贴其余节点
实现：前端 use-node-copy-paste.ts、use-overlay-open.ts、CanvasView.vue；后端 business/user_database/node 的 command/copy 与 service/copy

## 删除与级联语义

### 逻辑删除、物理删除与恢复

定义：逻辑删除可回收，节点进入回收站并保留边关系，恢复后相连的边自动重新显示；物理删除不可逆，级联删除相连的边、字段、附件及引用的画布；恢复操作沿级联关系连带恢复。
联动：逻辑删除画布数据节点 → 级联逻辑删除引用的子画布；恢复画布数据节点 → 级联恢复引用的子画布
实现：后端 business/user_database/node/service/logical_delete、physical_delete、restore 与 canvas/service 同名模块；前端 RecycleBinPanel.vue、CanvasRecycleBinPanel.vue

### 回收站

定义：逻辑删除节点的暂存区，支持恢复、物理删除与清空；画布宇宙与画布页面各有独立的回收站。
实现：后端 business/user_database/node/service/logical_delete、restore；前端 RecycleBinPanel.vue、CanvasRecycleBinPanel.vue

### 级联坍塌

定义：边删除引发的级联删除链条——边删除导致其产生的影子级联删除，影子的相连边随之级联删除，由外键沿相反方向递归级联删除的影子及其相连边构成的整体（“影子子树”，可分支、可跨多级画布）随之坍塌；画布删除引发子画布与引用节点的级联删除。
不变量：影子坍塌完全由外键级联完成，应用层禁止手写递归删除影子
实现：后端 business/user_database/edge/service/delete、node/service/physical_delete、canvas/service/physical_delete

### 影子断连收集

定义：删除边或物理删除节点前，沿"边 → 产生的影子 → 影子的相连边 → 嵌套影子"递归预收集将失去连接的节点标题，供用户确认。
不变量：影子方向必然可推导、影子的邻居必然非影子，任何不一致返回 DataCorruption 系列错误
实现：后端 business/user_database/shadow/service/shadow_disconnected；前端 CanvasView.vue、EdgeContextMenu.vue

### 跨画布迁移

定义：节点在画布之间移动，落点可以是画布数据节点、出向影子节点或面包屑祖先片段，目标画布依次为落点引用的子画布、落点本体引用的子画布与片段对应的祖先画布；迁移时需校验节点同属一画布、无外部边、不含影子或画布数据节点。
联动：跨画布迁移节点 → 内部边随节点一并迁移至目标画布
实现：后端 business/user_database/node/service/relocate_nodes；前端 use-node-move-and-relocate.ts

## 安全与完整性

### 加密与密钥

定义：用户数据库采用文件级加密，字段值采用字段级加密；密钥由用户密码派生，随数据库打开载入全局状态，用于字段值与日志数据的加解密。
实现：后端 security、business/user_database/state；前端 Home.vue

### 压缩 guard

定义：附件明文导入时按内容类型分拣到不同编码器压缩后再加密；读取时解密后按压缩标记解压还原。压缩参数经 CompressParam 序列化存入附件元数据。
实现：后端 util/compress/guard；前端 views/DatabaseComponents/attachment 目录

### 备份包

定义：数据目录级全量备份（排除日志目录），采用自定义二进制格式，包含固定头部、分片校验和表与分片区，支持分片级容错恢复。
实现：后端 business/backup/format；前端 Home.vue 备份还原功能

### 受控崩溃

定义：DataCorruption 系列错误码表示数据损坏或程序缺陷导致的不变量破坏；后端一律返回错误绝不静默放行或降级。
联动：前端收到 DataCorruption 系列错误 → 弹出阻塞式对话框 → 用户确认后调用 fatal_exit 接口 → 后端记录日志后以非零码退出进程，不触发退出保存逻辑，避免脏数据写盘
实现：后端 error_code、business/fatal_exit；前端 use-fatal-error.ts、FatalErrorDialog.vue

### 内存刷新

定义：磁盘文件被外部刷新（如备份还原）后，通知各业务模块重新读取磁盘文件替换内存状态，避免关闭程序时用旧的内存数据覆盖磁盘新数据。
联动：备份还原完成 → 触发内存刷新 → 各模块重新读取磁盘文件
实现：后端 business/reclaim；前端 Home.vue

### 数据版本

定义：数据库结构版本，通过数据库连接模块透明渗透至各业务模块；版本不匹配时拒绝打开数据库。
联动：启动期偏好或元数据数据库初始化失败（含版本不匹配）→ 记录日志并按系统语言弹出面向终端用户的友好提示的原生阻塞对话框（文案见概念地图·国际化）→ 用户确认后以非零码退出进程（启动阶段前端尚未就绪，受控崩溃通道不可用，故不经 FatalErrorDialog）
实现：后端 common/data_version、startup_error（启动期提示退出）、lib.rs；前端 Home.vue

## 前后端契约

### command 与 ErrorCode

定义：前端经 api.ts 封装调用 tauri command；错误以 ErrorCode 传输，部分错误码限定在特定模块内使用。
实现：后端 lib.rs command 注册、error_code.rs；前端 api.ts、error-code.ts

### 传输类型（VO）

定义：前端 api-types.ts 与后端 vo/response 类型一一对应，字段命名与后端 serde 序列化结果保持一致。
实现：后端 business/user_database/*/vo、log/response；前端 api-types.ts

### 国际化

定义：面向用户的固定文案与代码分离并按语言分别定义——前端文案由前端 i18n 模块按模块与语言组织，后端文案（启动期错误提示、导出 markdown 的固定文案）统一定义于后端 i18n 模块并支持中文与英文。
不变量：后端取文案时语言可缺省，缺省取系统当前语言；运行期由前端传入的语言代码无法识别时按缺省处理（前端充当语言 gate）；后端日志与 panic 文本一律英文，不属于国际化范围。
实现：后端 i18n、startup_error、business/user_database/export；前端 i18n/index.ts

### 最后场景

定义：关闭数据库时记录当前页面位置（画布宇宙记为空值），下次打开数据库时自动恢复；没有或不适用则默认进入画布宇宙页面。
实现：后端 business/user_database/registry；前端 DatabaseView.vue、Home.vue

### 主题与偏好

定义：用户偏好存于偏好数据库；主题支持自定义、导入导出，内置主题与自定义主题通过 Vuetify 主题表管理。
实现：后端 business/preference；前端 themes/index.ts、preferences.ts

## startup_error.rs 文件

说明：启动期错误处理，启动阶段偏好或元数据数据库初始化失败时按系统语言取终端用户友好的提示文本，弹出原生阻塞对话框告知用户，待用户确认后以非零码退出进程
稳定契约名：Database 类型
联动关系：由 lib.rs 的启动初始化流程在数据库初始化失败时调用；提示文案经后端 i18n 模块按系统语言取用（见概念地图·国际化），其退出不触发退出保存逻辑（见概念地图·数据版本、受控崩溃）

## state.rs 文件

说明：全局路径状态，持有应用数据目录、日志目录、用户数据库集合目录、偏好数据库文件与元数据数据库文件等路径，程序启动时写入、此后各处读取，并提供由用户数据库 id 推导其目录、数据库文件与附件文件路径的辅助，以及对导出目标路径必须位于数据目录之外的校验
稳定契约名：Path 类型、ErrorCode 的 InvalidExportTargetPath
联动关系：路径集合由 lib.rs 初始化数据目录后写入；导出等写操作经其校验目标路径，以保护数据目录下的用户数据库文件与附件文件（见概念地图·导出、用户数据库与元数据）

## test.rs 文件

说明：后端测试辅助套件，提供串行化依赖全局状态的测试的全局测试锁、位于项目构建产物目录下的测试数据目录构造与清理，以及固定测试密钥
联动关系：被依赖全局路径状态或数据库连接状态的单元测试调用，避免并行测试相互干扰
