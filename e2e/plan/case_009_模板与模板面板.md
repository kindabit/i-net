# case_009 模板与模板面板

## 测试主题

覆盖模板的完整管理流程：从节点保存为模板、模板管理对话框的新建/重命名/删除/字段结构编辑/保存、未保存修改关闭确认、模板导入导出（SQLite 文件），以及用模板拖拽创建数据节点与画布数据节点并验证字段结构继承。本用例验证「模板定义 → 模板维护 → 模板创建节点 → 导入导出」链路。

## 前置条件

- 复制 fixture `base` 到 `<case>\output\data` 并以该目录启动应用
- 解锁 `zz-e2e-base` / `e2e-password`，位于根画布（若停在画布宇宙则双击「根画布」进入）
- 界面语言：中文
- fixture 无模板（模板列表为空）

## 覆盖范围

前端功能点：
- 模板面板：`title="新建节点"` 打开；「空节点」行与模板行；每行两个拖拽手柄（`title="拖拽创建数据节点"`、`title="拖拽创建画布数据节点"`）；`title="管理模板"` 按钮
- 模板管理对话框：新建模板（NameInputDialog）、重命名、删除（确认框）、字段结构编辑（字段名输入、类型下拉、拖拽手柄、删除字段）、保存按钮 dirty 才可用、模板切换时的未保存确认、关闭时的未保存确认
- 从节点保存为模板（编辑节点对话框左下按钮「保存为模板」→ 名称输入对话框 → snackbar）
- 模板拖拽创建：数据节点副标题为模板名，字段结构继承；画布数据节点同样继承
- 模板导出为 SQLite 文件（FilePicker save、默认文件名 `templates.sqlite`）
- 模板导入（替换确认 + FilePicker open，覆盖模板与字典数据）

后端命令（经由 UI 触发）：
- `user_database_template_create`、`user_database_template_create_from_node`
- `user_database_template_list`、`user_database_template_get_fields`、`user_database_template_set_fields`
- `user_database_template_rename`、`user_database_template_delete`
- `user_database_template_export`、`user_database_template_import`
- `user_database_node_create`（`templateId` 参数两种模式）
- `user_database_node_modify`、`user_database_node_field_set`（保存为模板前保存节点改动）
- `user_database_dictionary_list` / `user_database_dictionary_set`（导入替换字典）
- `file_system_list_directory` / `file_system_roots` / `file_system_path_exists`（文件选择器）

## UI 操作流程与预期结果

| # | 操作 | 预期结果 |
|---|------|----------|
| 1 | 点击悬浮菜单 `title="新建节点"` 展开模板面板 | 面板出现「空节点」行与两个拖拽手柄、`title="管理模板"` 按钮；模板列表为空（仅有「空节点」）；截图留档 |
| 2 | 点击 `title="管理模板"` | 模板面板关闭；打开对话框「模板管理」；左侧「新建模板」按钮，右侧提示「请选择或新建一个模板」 |
| 3 | 点击「新建模板」 | 弹出名称输入对话框：标题「新建模板」、label「模板名称」 |
| 4 | 输入 `登录凭证`，点击「确认」 | 模板列表出现「登录凭证」并被选中；字段区为空 |
| 5 | 点击「添加字段」，在字段名输入框输入 `用户名` | 出现字段行「用户名」，类型为「单行文本」 |
| 6 | 再次点击「添加字段」，字段名输入 `密码`；点击该行类型下拉并选择「密码」 | 两个字段行：`用户名`（单行文本）、`密码`（密码） |
| 7 | 点击「保存」 | snackbar「模板已保存」；「保存」按钮变为不可用（无未保存修改） |
| 8 | 点击 `title="重命名模板"`，输入 `登录凭证 2`，点击「确认」 | 列表项与右侧标题更新为「登录凭证 2」；截图留档 |
| 9 | 点击「添加字段」制造未保存修改，点击对话框「取消」 | 弹出确认框：标题「未保存的修改」、正文「当前编辑有未保存的修改，确定要放弃吗？」 |
| 10 | 点击确认框「取消」，再点击「取消」，在确认框中点击「确认」 | 取消时留在编辑器；确认后对话框关闭、修改被放弃 |
| 11 | 双击「账号 A」打开编辑对话框，点击「添加字段」，输入字段名 `邮箱` | 「账号 A」新增字段行「邮箱」 |
| 12 | 点击左下角「保存为模板」 | 先保存节点改动，再弹出名称输入对话框：标题「保存为模板」、label「模板名称」、确认按钮「保存为模板」 |
| 13 | 输入 `账号模板`，点击「保存为模板」 | snackbar「模板已创建」；名称对话框关闭（编辑对话框保持打开） |
| 14 | 点击编辑对话框「确认」；再次打开模板面板 | 面板中出现「登录凭证 2」「账号模板」两行，各带两个拖拽手柄 |
| 15 | 从「登录凭证 2」行的 `title="拖拽创建数据节点"` 手柄拖到画布空白处 | 画布出现节点「新节点」，副标题为「登录凭证 2」；模板面板自动关闭；截图留档 |
| 16 | 双击新节点打开编辑对话框 | 字段区包含字段「用户名」与「密码」（字段结构继承，值按类型为空）；截图留档 |
| 17 | 点击「取消」关闭；再次打开模板面板，从「登录凭证 2」行的 `title="拖拽创建画布数据节点"` 手柄拖到画布空白处 | 画布出现画布数据节点「新画布」，副标题为「登录凭证 2」（子画布已创建） |
| 18 | 打开「管理模板」，点击「导出模板」 | 打开文件选择器（save 模式、默认文件名 `templates.sqlite`） |
| 19 | 路径框输入 `<case>\output`，文件名保持 `templates.sqlite`，点击「确认」 | snackbar「模板已导出」；脚本断言 `<case>\output\templates.sqlite` 存在且文件头为 SQLite 格式 |
| 20 | 在模板列表选中「账号模板」，点击 `title="删除模板"` | 确认框：标题「删除模板」、正文「确定要删除模板"账号模板"吗？其字段结构将一并删除。」 |
| 21 | 点击「确认」 | 列表中「账号模板」消失（失败路径 F2 的对照组） |
| 22 | 点击「导入模板」 | 确认框：标题「导入模板」、正文「导入将替换当前所有模板和字典数据，确定继续吗？」 |
| 23 | 点击「确认」 | 打开文件选择器（open 模式） |
| 24 | 通过路径框导航到 `<case>\output`，双击 `templates.sqlite` | snackbar「模板已导入」；列表重新出现「账号模板」（导入文件为其导出时内容）；模板面板中模板行同步更新 |

## 失败路径

| # | 失败场景 | 对应步骤 | 预期结果 |
|---|----------|----------|----------|
| F1 | 新建模板名称为空 | 3 | 名称输入对话框「确认」按钮保持禁用，无法提交 |
| F2 | 新建模板名与已有模板重名（`登录凭证 2`） | 3 之后复测 | snackbar 提示「模板名称已存在」（正文「名称：登录凭证 2」）；不创建 |
| F3 | 模板字段名为空 / 重复时保存 | 5–7 之间复测 | 内联提示「字段名不能为空」/「字段名重复」，保存被阻止，对话框不关闭 |
| F4 | 模板有未保存修改时切换其它模板 | 9 变体 | 弹出「未保存的修改」确认框；取消则留在当前模板 |
| F5 | 导入确认框取消 | 22 | 不打开文件选择器，模板数据不变 |

## 脚本资产需求

- 无预置资产；导出产生的 `templates.sqlite` 留在 `output\` 并作为导入源使用
- 关键步骤截图（空模板面板、模板管理初始态、字段编辑、保存后、重命名后、未保存确认框、保存为模板对话框、模板创建节点、字段继承、导出成功、导入后）存入 `output\`

## 备注与风险

- 模板面板没有「双击创建节点」入口，只有两个拖拽手柄；拖拽落点不做 20px 吸附。
- 模板管理对话框的关闭按钮为「取消」；未保存修改确认在对话框关闭与切换模板两个时机都会触发。
- 模板字段名是普通输入框（无单击进入编辑态的交互，与节点字段名不同）；类型下拉与节点字段一致按底层类型分组。
- `TemplateNameAlreadyExists` 由后端校验；前端名称对话框只做空值禁用。
- 导入前必须先导出（或外部准备）合法 SQLite 模板文件；导入是整体替换（含字典），导入前删除的模板会在导入后恢复，可用于验证替换语义。
- `template_export` / `template_import` 未限制目标路径位于数据目录内（与数据库导出不同），本用例输出到 `output\` 不影响数据目录。
- 编辑节点对话框为 `persistent`；「保存为模板」会先保存节点当前改动后再创建模板。
