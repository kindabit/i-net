# case_004 画布节点基础操作（修订版）

> 本文件是 `case_004_画布节点基础操作.md` 的修订版：在执行计划主流程实测后，修正了与实现不一致或无法执行下去的测试条件。修订点见文末「修订记录」。

## 测试主题

在根画布内完成数据节点的基础操作：模板面板拖拽创建、编辑标题与副标题（双击与按钮两种入口）、复制节点、自定义颜色、逻辑删除与回收站恢复/永久删除、框选批量移动（20px 网格吸附）与画布视口缩放持久化。本用例验证「节点创建 → 编辑 → 复制 → 删除恢复 → 批量移动 → 视口保持」链路。

## 前置条件

- 复制 fixture `base` 到 `<case>\output\data` 并以该目录启动应用
- 解锁 `zz-e2e-base` / `e2e-password`，位于根画布（若停在画布宇宙则双击「根画布」进入）
- 界面语言：中文
- fixture 已有节点「账号 A」「备注 B」（副标题均为「空节点」）

## 覆盖范围

前端功能点：
- 悬浮菜单「新建节点」展开/收起模板面板（与回收站面板互斥）
- 「拖拽创建数据节点」手柄拖拽创建普通数据节点（标题「新节点」）
- 编辑节点对话框：双击卡片与 hover 铅笔按钮（`title="编辑节点"`）两个入口；标题/副标题修改；标题为空校验
- 复制节点：hover 按钮 `title="复制节点"`，副本出现在视口中央且坐标按 20px 取整
- 节点自定义颜色对话框（`title="自定义颜色"`）预设选择与保存
- 逻辑删除节点（无确认框）与回收站面板恢复/永久删除/清空入口
- 框选多个节点、批量移动（松开后一次 `move_nodes` 提交）；拖动吸附 20px 网格
- 画布视口缩放持久化（切换到画布宇宙再返回后保持）
- 画布内悬浮菜单按钮可见性（新建节点/回收站/字典管理/自动布局）

后端命令（经由 UI 触发）：
- `user_database_node_create`（拖拽创建）
- `user_database_node_modify`（标题/副标题保存）
- `user_database_node_copy`（复制）
- `user_database_data_node_set_color`、`user_database_data_node_color_list`（配色对话框）
- `user_database_node_logical_delete`、`user_database_node_restore`、`user_database_node_physical_delete`
- `user_database_node_list`（画布加载与回收站）
- `user_database_node_move_nodes`（批量移动）
- `user_database_viewport_get` / `user_database_viewport_set`（画布视口）
- `user_database_canvas_list`（画布宇宙返回时加载）

## 备注与风险

- 节点**没有右键菜单**（右键仅阻止原生菜单）：编辑/复制/附件/配色/删除入口是 hover 时淡入的按钮排；Delete/Backspace 删除已被禁用。
- 拖拽创建节点使用 `screenToFlowCoordinate` 直出坐标，**不吸附 20px 网格**；网格吸附只作用于节点拖动（vue-flow `snap-to-grid`）。落点为节点左上角。
- 节点尺寸固定 160×80 CSS 像素（10rem×5rem，zoom=1 时）；测试机 DPI 缩放 1.5，UI 树 bounds 为窗口物理像素（160×80 CSS = 240×120 物理）。
- 编辑节点对话框为 `persistent`，Esc 与遮罩不关闭（避免与字段名编辑的 Esc 冲突），只能通过按钮关闭。
- 逻辑删除无确认框；永久删除与清空回收站有确认框；确认框「取消」按钮文案为「取消」，确认按钮文案为「确认」。
- 复制节点落点取画布视口正中央并按 20px 取整；副本继承标题、副标题、颜色与字段结构（不含字段值与附件、边）。
- 视口 `set` 有 500ms 防抖、切换路由时 flush；本用例只验证切换后保持，重启落盘验证在 case_015。
- 节点操作按钮为 hover 淡入（0.15s）；按钮在鼠标离开卡片后仍会以离场动画短暂留在 DOM 中，脚本定位按钮时须同时校验按钮 bounds 位于目标卡片正上方（否则可能点到上一个节点的按钮）。
- 框选依赖 vue-flow `selection-key-code=true`（左键直接框选，无需修饰键）；**vue-flow 默认 `SelectionMode.Full`**：只有被框选矩形**完全包含**的节点才会被选中（部分相交不选中），框选矩形须完全包住全部目标节点且不完整包含其它节点。
- 多节点被选中期间，vue-flow 会渲染 `nodesselection` 选中叠层，遮挡过滤会把选中节点连同其文本从 UI 树中剔除；断言选中期间只能截图核对，节点 bounds/坐标需先点击空白取消选中后再从 UI 树读取。
- 预构建调试可执行文件的前端为生产构建（`DEBUG=false`），`NodeDebugOverlay`/`ViewportDebugOverlay` 被条件编译剔除，无法读取画布坐标；20px 网格对齐改以物理像素验证：节点卡片固定 160 画布像素宽（zoom=1 时为 240 物理像素），由卡片宽度换算 DPI（1.5），吸附后的节点位置两两同余于 20 画布像素；副本落点按 20px 取整由「对其做 +37 物理像素吸附拖动，位移恰为 20 画布像素」反证（未取整的落点会带出相对网格的偏移）。
- 输入注入存在事件合并的时序风险：快速移动后立即松开可能丢失最后一次 mousemove，使拖动位移偏小；拖动命令须分阶段移动并在最后阶段后等待约 400ms 再松开（实测该模式稳定）。
- 数据节点配色对话框的色块已具备可访问名称（2026-09-21 修复）：预设组合色块以 `role="button"` + `aria-label`（tooltip 文案，蓝/绿/紫/橙/青/粉/灰）入 UI 树，字段色块以 `role="button"` + `aria-label`（「亮色主题/暗色主题 + 字段名」）入 UI 树；hover 后 tooltip 以 `role=tooltip` 节点入 UI 树（移开后消失）。脚本按 role=button + name 定位并点击色块，不再按「预设组合」标题的相对位置推算坐标。

## 修订记录

1. **步骤 1**：补充「模板面板与回收站面板互斥」的显式验证（原计划仅在覆盖范围提及；互斥由 `onTemplatePanelToggle`/`onRecycleBinToggle` 实现，脚本以「打开回收站后模板手柄消失、重新展开模板面板」验证）。
2. **步骤 7**：副本落点断言补充「按 20px 取整」的验证方式（预构建可执行文件无调试叠层后改为吸附拖动位移反证），并明确副本位置以视口中部区域 + 20px 取整核对。
3. **步骤 11**：明确框选矩形必须**完全包含**目标节点——vue-flow 默认 `SelectionMode.Full`，部分相交不会选中；原计划未说明，实测第一次框选（未包含副本）仅选中两个节点。随机化落点与框选范围改为「运行时按三个节点实际 bounds 计算框选矩形」，并校验不完整包含 fixture 节点。
4. **步骤 12**：修订为两阶段可执行序列——第一次批量拖动（+37 物理像素）使三个选中节点全部吸附网格；因选中叠层会遮挡节点、UI 树无法读取选中节点，须先点击空白取消选中以读取 bounds 并断言网格对齐，再重新框选进行第二次批量拖动（+53 物理像素）；断言第二次位移为 60 物理像素（40 画布像素）且三个节点一致。拖动命令改为分阶段移动 + 松手前等待（规避输入事件合并）。
5. **步骤 19（原）**：原步骤 19「再次逻辑删除「节点乙」后清空回收站」在原步骤 18 已永久删除「节点乙」后无法执行；修订为**重建**一个名为「节点乙」的节点、逻辑删除后再验证清空回收站（与 case_003 修订版同一处理方式）。
6. **步骤 21（新增）**：把原 F4 的可选断言纳入正式流程（选中节点后按 Delete/Backspace，断言节点仍存在）。
7. **备注**：新增框选全包含语义、选中叠层遮挡、hover 按钮离场残留、输入事件合并分阶段拖动、DPI 1.5 等实测结论。
8. **修复追溯（2026-09-21）**：应用修复（2026-09-21）第 3 条（原「无文本锚点的色块与 tooltip」能力边界）已落地（`ColorPairSwatch.vue`、`ColorFieldEditor.vue` 补 `role="button"` + `aria-label`；`EditDataNodeColorDialog.vue` 传入「亮色/暗色主题 + 字段名」的 `swatch-aria-label`；`ui_tree_bridge.js` 对 `role=tooltip` 悬浮子树在可见期间豁免遮挡判定）。据此修订步骤 8-9 的色块定位方式与断言：由「按『预设组合』标题相对坐标推算 + tooltip 截图核对」改为「按 role=button + name 定位色块」，新增「预设组合 7 个色块、亮/暗主题各 8 个字段色块以 role=button + name 入树」「hover『绿』色块后 role=tooltip 节点文本为『绿』、鼠标移开后消失」三类断言；原有对话框结构、预设色值回填与节点像素断言全部保留。同步更新脚本头部注释与上文备注条目。
