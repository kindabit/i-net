# case_007 跨画布结构与迁移（修订版）

> 本文件为 `case_007_跨画布结构与迁移.md` 的修订版，随正式脚本 `e2e\script\case_007\case_007.js` 一同交付；

## 测试主题

构造多级画布结构，验证画布数据节点与子画布导航：面包屑层级折叠与省略号菜单、影子虚拟边点击跳转、Alt 拖拽跨画布迁移（画布数据节点落点与面包屑落点两条合法路径，以及影子节点/画布数据节点/含外部边节点集三条非法提示）、反向替换伴随断连的确认对话框。本用例验证「多级画布导航 → 跨画布迁移 → 替换断连确认」链路。

## 前置条件

- 复制 fixture `base` 到 `<case>\output\data` 并以该目录启动应用
- 解锁 `zz-e2e-base` / `e2e-password`，位于根画布（若停在画布宇宙则双击「根画布」进入）
- 界面语言：中文
- fixture 已有节点「账号 A」「备注 B」及二者之间的边

## 覆盖范围

前端功能点：
- 画布数据节点创建与重命名（重命名同步画布名）
- 双击画布数据节点进入子画布；多级层级（4 层画布链）面包屑折叠为「根画布 / … / 上一级 / 当前」
- 面包屑省略号菜单列出被隐藏层级并可跳转
- 影子节点（入向/出向）的出现与影子虚拟边（`title="入度来自画布之外，点击定位至产生该影子的边"` / `title="出度指向画布之外，点击定位至产生该影子的边"`）点击跳转回产生边所在画布
- Alt + 拖拽跨画布迁移：按住 Alt 后拖动节点，落点为画布数据节点、出向影子节点或面包屑可跳转祖先片段
- 非法迁移三种 snackbar 提示（影子节点、画布数据节点、含外部边节点集）
- 反向连接替换触发「替换连接将断开节点连接」确认框（`replace-edge-confirm` 按钮）

后端命令（经由 UI 触发）：
- `user_database_node_create`（画布数据节点及子画布、普通节点）
- `user_database_node_modify`（节点/画布重命名）
- `user_database_node_relocate_nodes`（Alt 迁移，含非法场景下的后端兜底）
- `user_database_node_move_nodes`（非法迁移回退为画布内移动）
- `user_database_edge_create`（含反向替换与断连确认 `confirmed=true`）
- `user_database_edge_get`（虚拟边点击定位产生边）
- `user_database_viewport_get`（迁移目标画布视口中心换算）
- `user_database_node_list`（各级画布加载）
- `user_database_canvas_list`、`user_database_registry_set`（场景切换）

## 备注与风险

- Alt 迁移要求「先按住 Alt 再开始拖动」或「拖动中按 Alt」（二者等价，均把状态机切到 relocate 模式）；非法提示在**松开鼠标时**出现，因此每个非法场景必须在松开前把光标拖到合法目标类型上（画布数据节点/出向影子/面包屑祖先片段），否则会按普通画布内移动处理而不提示。
- **Alt 组合拖拽必须整段放在同一个 `/input` 请求里**：每个请求结束会析构原生输入句柄并释放仍按下的按键，跨请求保持 Alt 会让状态机复位（实测表现为普通画布内移动）。配方：`keyPress(Alt)` → 移动到起点 → `mousePress` → 抖动 → 分阶段移动 → 停在落点 → `mouseRelease` → `keyRelease(Alt)`。
- 拖动中节点卡片跟随光标且始终位于命中序列首位：目标卡片的 bounds 须在拖动前采集；被拖拽的画布数据节点自身会先命中 `canvasRefId`，因此 F3 的落点高亮出现在被拖拽节点上（见修订记录）。
- 落点高亮的截图验证需在拖动保持期间并发请求 `/screenshot`：命令注入每条约有百毫秒固定开销，保持时刻无法精确预估，脚本按多个时间点轮询取评分最高帧。
- 面包屑落点仅接受带 `data-canvas-id` 的可跳转祖先片段（根画布片段合法；「画布宇宙」片段、当前画布片段、省略号菜单项不是合法落点）。
- 迁移后坐标由前端按目标画布持久化视口中心换算并 20px 取整，后端只校验与落库；断言位置时取目标画布视口中心 ±20% 容差。
- 面包屑折叠阈值为画布链长 ≥4；省略号菜单项点击后跳转层级。
- 影子虚拟边是节点卡片外侧自绘的虚线元素（非 vue-flow 边），现已作为 `role="button"` 节点进入 UI 树（name 为对应方向的 hint 文案、bounds 为 40×10 CSS 像素），入向虚拟边位于卡片左侧、出向位于右侧；定位与点击基于该 UI 树节点，点击后携带 `edgeId` query 跳转并 300ms 居中（入向与出向各自验证）。
- 反向替换的断连确认依赖旧边（工作区→参考区）的出向影子在子画布中有关联节点（节点 C）；若关联节点缺失则不弹确认框，构造步骤不可省略。
- 非法迁移仍会按画布内移动持久化：脚本在 F1 后把「账号 A」、F2 后把影子节点挪回空白区，避免被拖拽残留位置遮挡「工作区」卡片或面包屑片段（属脚本卫生动作，不影响断言语义）。
