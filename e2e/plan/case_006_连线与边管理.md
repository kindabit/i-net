# case_006 连线与边管理（修订版）

> 本文件是 `case_006_连线与边管理.md` 的修订版：在执行计划的过程中真实发现了无法照原样执行下去的部分（删除产生边后影子相连边一并级联删除，重建产生边后影子已无关联节点，直接删除影子不会触发断连确认框），以及若干与实现不一致的探测/断言细节。修订后的完整计划见下文，逐条修订记录见文末。

## 测试主题

在根画布内管理节点间连线：同向重复连接只更新连接桩、反向连接替换、边右键菜单编辑标题与详情、边删除（无断连与断连确认两种）、通过「数据节点 → 画布数据节点」连接产生跨画布影子节点、以及删除影子节点时触发的断连确认。本用例验证「建立连接 → 编辑/替换/删除 → 影子联动」链路。

## 前置条件

- 复制 fixture `base` 到 `<case>\output\data` 并以该目录启动应用
- 解锁 `zz-e2e-base` / `e2e-password`，位于根画布（若停在画布宇宙则双击「根画布」进入）
- 界面语言：中文
- fixture 已有边：账号 A → 备注 B（无边标题）

## 覆盖范围

前端功能点：
- 连接桩拖拽建立边、同向重复连接（不新增边）、反向连接替换
- 前端非法连接拦截：自环、两端连接桩相同
- 边的右键菜单（`编辑边` / `删除边`），边命中区在无标签时按曲线 t=0.5 探测、有标签后按标签文本定位
- 编辑边对话框：标题与详情修改；字段内容以「聚焦 → Ctrl+A → Ctrl+C → 读剪贴板」验证（UI 树不返回输入值）
- 删除边：无断连直接删除；有断连时弹「删除边将断开连接」确认框，确认后删除
- 画布内画布数据节点创建（`title="拖拽创建画布数据节点"`）与影子节点产生
- 删除影子节点：入口文案「删除影子节点（等同于删除产生它的边）」；有断连时弹「删除影子节点将断开连接」确认框

后端命令（经由 UI 触发）：
- `user_database_edge_create`（新建 / 同向更新 / 反向替换）
- `user_database_edge_update`（标题与详情）
- `user_database_edge_delete`（`confirmed=false/true` 两阶段）
- `user_database_edge_list`（画布加载）
- `user_database_edge_get`（影子虚拟边定位；本用例通过后端日志间接涉及）
- `user_database_node_create`（画布数据节点与普通节点）
- `user_database_node_modify`（节点改名）
- `user_database_node_list`（子画布加载，含影子节点合并展示）
- `user_database_node_logical_delete`（可能用于清理；可选）
- `user_database_canvas_list` / `user_database_registry_set`（场景切换）

## 备注与风险

- 边没有独立 DOM 节点暴露在 UI 树中：无标签时按「贝塞尔曲线在 t=0.5 处的点」右键（命中区为 20 单位宽的透明路径，zoom=1 时约 30 物理像素宽）。曲线控制点偏移公式见 `src\utils\custom-edge-geometry.ts`，脚本按同一公式计算探测点，并在 [0.5, 0.46, 0.54, 0.42, 0.58, ...] 中挑选远离节点卡片危险区的点做小范围重试；设置标题后改为右键标签文本「边一」的中心，稳定性更高。
- 节点卡片的 hover 操作工具条浮在卡片上方外侧，会在鼠标经过卡片后短暂驻留，并截获右键（表现为右键边无菜单的假阴性）。因此每次边探测前必须先把鼠标移到空白处等待 hover 退场（约 0.4 秒），且探测点必须位于「卡片外扩 + 顶部工具条桥接区」之外。
- 数据节点四个方向的连接桩均为 `source` 类型（`data-handleid` 为 top/bottom/left/right），定位沿用 fixture 构建脚本 `build.js` 的既有策略：按 `data-handlepos` 过滤连接桩，并取与节点卡片范围最近者。
- 同向重复连接不产生日志、不弹提示；以「标签数量不变 + 边右键菜单仍可命中」断言。
- 反向替换仅在旧边产生影子且影子在子画布中有关联节点时返回 `EdgeDeleteDisconnectsNodes`；本用例的无断连替换不弹确认框。替换继承标题与详情，可用重开编辑边对话框 + 剪贴板验证。
- 方向反转的视觉差异仅在箭头（目标端）位置：替换前后分别统计两端连接桩外侧小窗口内的灰度（#b1b1b7 邻域）像素数，目标端因箭头显著更多。
- 影子节点的连接方向限制：入向影子（数据节点的影子）只能作起点、出向影子（画布数据节点的影子）只能作终点；违反时前端拦截、后端兜底报 `InvalidShadowEdge`。
- 删除产生边会级联删除影子节点，以及影子在子画布内的相连边（外键级联）。因此删除产生边后重建产生边，影子虽重新出现，但其与子画布内节点的边不会恢复；要让「删除影子」触发断连确认框，必须先重建影子→子画布节点的边（见步骤 19b）。
- 影子节点的「虚线」外观：默认颜色下卡片边框为透明（`border-style: dashed` 不可见），可见的虚线元素是卡片外侧的入向/出向虚拟边（带行进动画的虚线 + 箭头）；脚本以「影子卡片存在 + 左侧虚拟边深色像素 + hover 按钮文案」断言影子语义。
- 影子节点不进入回收站，删除影子等于删除产生它的边；影子节点删除按钮文案与普通节点不同（`title` 区分），影子节点 hover 只出现「编辑节点」与删除两个按钮。
- 画布内「新画布」节点双击进入其子画布；从子画布返回使用面包屑「根画布」。
- 所有 hover 按钮需先移动鼠标到节点中心并等待约 0.15 秒淡入；定位按钮时校验 bounds 位于目标卡片工具条范围内，规避上一个节点的按钮离场残留。
- 对话框关闭后先等待「对话框消失 + 画布内容可读（目标文本重新出现）」再操作/断言，规避遮罩期间 UI 树过滤节点造成的瞬时误判。
- F1 自环曲线紧贴卡片右上角，其 t=0.5 点落在卡片内被遮蔽，单点探测不足以证明「无新边」；脚本补充全屏像素基线比对（两次非法拖拽前后截图差异为 0）。

## 修订记录

1. **步骤 19-21（结构性修订）**：原计划在步骤 18 影子级联消失后，于步骤 19 重建「账号 A」→「新画布」的边并直接删除影子。实际执行发现：删除产生边时，影子在子画布内的相连边（影子→节点 C）随外键级联一并删除；重建产生边只恢复影子本身，不恢复该相连边。后端 `collect_edge_disconnected` 仅在影子存在非影子邻居边时返回受影响节点，因此此时删除影子不会弹出断连确认框，步骤 20/21 的确认框与按钮文案断言均无法执行。修订为在步骤 19 后新增步骤 19b：重建「影子→节点 C」的边，再执行步骤 20/21 的断连确认取消与确认路径。
2. **步骤 1 与「备注与风险」（探测方法显式化）**：原计划仅写「按曲线中点右键，若未弹出按 ±8/±16 像素偏移重试」。实际执行发现两类假阴性：一是节点 hover 工具条会截获右键；二是边作为 `role=group` + `data-id` 的 SVG 元素会污染「节点卡片」筛选。修订为：探测前先清场等待 hover 退场、按卡片危险区（外扩 + 工具条桥接区）从候选 t 中挑选安全点、破坏卡片筛选的 `aria-roledescription` 条件显式化。
3. **步骤 5、6（字段值断言方式）**：UI 树永不返回输入框 `value`（见调试期自动化文档），原计划「对话框标题仍为 边一、详情仍为 详情一」无法直接从 UI 树读取。修订为聚焦输入框后 `Ctrl+A` / `Ctrl+C` 并读取系统剪贴板断言内容。
4. **步骤 6（方向反转断言）**：补充可执行断言——替换前后分别统计两端连接桩外侧小窗口的灰度像素数，断言箭头由 B 端换到 A 端（箭头位于目标端）。
5. **步骤 8-9、F1（断言增强）**：自环曲线的 t=0.5 点位于卡片内部（被卡片遮挡），单点右键探测不能证明「无新边」。修订为：曲线探测取卡片外可命中的点，并增加全屏像素基线比对（两次非法拖拽前后截图必须一致，实测差异为 0）。
6. **步骤 12（影子外观断言）**：原计划写「虚线卡片」，实际默认颜色下影子卡片边框透明、虚线仅体现在卡片外侧的虚拟边上。修订为以「影子卡片存在 + 左侧虚拟边深色像素（实测约 120+）+ hover 按钮文案」断言影子语义。
7. **步骤 15、17、20、21（对话框文案与按钮）**：明确断连确认框的完整正文与按钮文案；「删除边」「删除影子节点（等同于删除产生它的边）」与菜单项/按钮 title 同名，点击时必须在对话框子树内定位（本脚本已如此实现）。
8. **步骤 17、18（删除后的等待时序）**：点击确认后先等待「对话框消失 + 画布内容可读」再断言，规避对话框遮罩期间 UI 树过滤画布节点导致的瞬时误判（dry-run 中出现过确认后读取到「影子与节点 C 都不存在」的瞬时态）。
