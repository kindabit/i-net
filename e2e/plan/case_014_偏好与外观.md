# case_014 偏好与外观（修订版）

> 本文件是 `case_014_偏好与外观.md` 的修订版，记录并固化了与实测一致的计划内容；
> 修订点见文末「修订记录」。正式脚本：`e2e\script\case_014\case_014.js`（105 条断言全通过）。

## 测试主题

覆盖全局偏好与外观设置：语言切换（中文 ↔ English 即时生效）、主题切换与主题管理对话框
（新建/编辑/导出到剪贴板/删除/导入）、设置对话框（剪贴板超时滑块与保存）、关于对话框
（信息展示，不点击仓库链接）。本用例验证「偏好修改 → 全界面即时生效 → 持久化」链路。

## 前置条件

- 复制 fixture `base` 到 `<case>\output\data` 并以该目录启动应用
- 解锁 `zz-e2e-base` / `e2e-password`，位于根画布（右上角浮动操作区在任意页面可见）
- 初始界面语言：中文；初始主题：亮色（默认）
- 脚本需读写系统剪贴板（主题导出与导入用）

## 覆盖范围

前端功能点：
- 右上角浮动操作区四个入口：`aria-label` 为「切换语言」「设置」「切换主题」「关于」
- 语言菜单：选项「English」「简体中文」（English 在前），当前项带整行高亮标记；点击项后菜单自动关闭；
  切换后界面文案即时变化（`title="搜索"` ↔ `title="Search"`、`aria-label` 全家随语言切换）
- 主题菜单：内置主题分组（亮色/暗色/海洋/森林）、自定义主题分组（仅在有自定义主题时渲染）、
  当前主题高亮标记、「管理主题」入口；`close-on-content-click=false`，点击主题项后菜单保持打开

  编辑（标识不可改）、导出（复制 JSON 到剪贴板）、删除（确认框）、导入（粘贴 JSON）
- 主题编辑校验：标识为空 / 显示名称为空 / 标识与内置冲突 / 标识已存在
- 设置对话框：剪贴板超时滑块（1–60 秒、步长 1、刻度 1/10/30/60）与保存（无 snackbar）
- 关于对话框：版本、作者、GitHub 仓库、Rust/Tauri/Vue/Vuetify 版本与简介（**绝不点击仓库链接**）

后端命令（经由 UI 触发）：
- `preference_get` / `preference_set` / `preference_save`（`locale`、`themeName`、`clipboard_clear_timeout`）
- `app_info_get`（关于对话框）

## 备注与风险（实测）

- 「关于」对话框的「GitHub 仓库」为 `span role="button"`，点击会调用系统默认浏览器打开外部页面；
  计划明确**不点击该链接**，只断言其文本（`ownText` 以 `https://` 开头）；源码中不存在 `href` 属性。
- 语言与主题切换的入口在右上角全局浮动操作区（App.vue），不是页面顶栏组件。
- 语言切换写偏好 `locale`；主题标识写在偏好 `themeName`；设置保存写 `clipboard_clear_timeout`；
  均为 `preference_set` + `preference_save`。
- 语言/主题菜单项顺序由 `Object.keys(messages)` 与 `themeList` 决定：语言菜单 English 在前、简体中文在后。
- **菜单开关行为（实测）**：语言菜单点击菜单项后自动关闭（VMenu 默认行为）；主题菜单
  `close-on-content-click=false`，点击主题项后保持打开，需再点主题按钮（activator toggle）收起。
- **菜单关闭与 UI 树/截图的时序（实测）**：菜单关闭瞬间 UI 树即过滤掉菜单项（overlay 的 aria-hidden），
  但视觉退出动画约 0.25–0.4 秒；UI 树判定「已关闭」后需再等待约 600ms 才能截到无菜单残留的画面。
- **当前项高亮标记不在 UI 树暴露**（`states.selected` 恒为 false）：脚本以截图像素统计断言
  （亮色主题下激活行有整行灰色高亮背景，实测激活 ≈ 97%、非激活 < 2%；阈值 4000/800）。
- **滑块 thumb 标签不进入 UI 树**：`show-ticks="always"` 的刻度文本（1/10/30/60 秒）在树中，
  但 thumb 标签（「5秒」）仅在视觉层；以 `aria-valuenow` + 截图 + thumb 上方深灰标签像素断言
  （实测标签出现 ≈ 1900 像素，阈值 600）。
- 主题导出写入系统剪贴板（`navigator.clipboard.writeText`）；脚本读回验证后立即解析并落盘。
- **剪贴板倒计时机制**：`startCountdown` 仅由字段值编辑器的复制操作触发（`FieldValueEditor`），
  外部写剪贴板不会启动清空倒计时；计划备注明确「本用例不复制字段值」，因此不做「写剪贴板 → 等超时 →
  断言清空」的验证；设置保存的验证口径为「保存后重开对话框值保持」。
- 主题编辑中的颜色修改使用 VColorPicker，交互面较大；本用例只覆盖显示名称修改（颜色行存在性同日验证），
  颜色编辑记录为可选扩展。
- 导入主题的名称冲突校验、保留名校验（内置名）在导入路径分别有独立文案；F5 只覆盖格式非法分支。
- 「编辑主题」时「主题标识」为 disabled 输入框，无法聚焦复制其值；脚本断言 `states.disabled` +
  保存后列表行副标题仍为 `custom-e2e-test`。
- **色块语义（修复后实测）**：主题编辑器 8 项核心颜色色块为原生 `button`，以 `role=button` +
  name（「背景/表面/主色/次要色/成功色/警告色/错误色/信息色」，即 `themes.colors.*` 文案）入 UI 树；
  该对话框不使用 `ColorFieldEditor`，色块无 tooltip（hover 前后 `role=tooltip` 节点数均为 0）。
  修复记录中补语义的 `ColorPairSwatch` / `ColorFieldEditor` 属节点颜色对话框（case_004 范围）。

## 修订记录

1. **语言/主题菜单关闭行为（核心实测固化）**：原计划未区分两种菜单的关闭策略。实测语言菜单点击项后
   自动关闭、主题菜单点击项后保持打开（`App.vue` 对主题菜单显式设置 `close-on-content-click=false`）。
   修订：步骤 6 改为「点击暗色（菜单保持打开）→ 点主题按钮收起 → 重开 → 点亮色 → 收起」。
   另固化「菜单关闭瞬间 UI 树即过滤、视觉动画滞后」的时序，截图前增加等待。
2. **「当前项标记」断言方式**：原计划预设菜单项有可断言的当前标记；实测 `active` 不在 UI 树
   `states` 中暴露。修订为截图像素统计（整行高亮背景像素）并保留截图。
3. **步骤 4 的自定义分组**：源码 `v-if="customItems.length > 0"`，初始无自定义主题时不渲染
   「自定义主题」分组。修订为「初始只显示内置分组」，并在步骤 15b（导入成功后）补充自定义分组
   出现的断言。
4. **滑块提示文本**：thumb 标签（「5秒」）不进入 UI 树。修订为 `aria-valuenow` + 刻度文本 + 截图
   thumb 标签像素断言。
5. **步骤 18「无 snackbar」判定口径**：明确为「保存前后底部 #text 文本集合无新增」。
6. **编辑态标识读值**：disabled 输入框无法经剪贴板读值，改为 `states.disabled` 断言 + 保存后
   列表行标识不变断言。
7. **F1/F2 与 F3/F4 的会话组织**：F1/F2 在同一次新建会话中先后验证（F1 清空标识 → F2 输入标识后
   清空显示名）；F3/F4 在步骤 9 保存成功后的第二次新建会话中验证（编辑器关闭时才可再次点击
   「新建主题」）。
8. **主题导出 JSON 落盘**：新增脚本资产 `output\theme-export.json`，导入步骤回写剪贴板
   （PowerShell `Set-Clipboard`，UTF-8 读取）。
9. **步骤 11 剪贴板断言细化**：解析 JSON 后断言 `name`/`displayName`/`dark`/`colors` 四个字段，
   替代「非空且包含主题标识」的粗粒度断言。
10. **补充收尾断言**：用例结束时界面语言为中文、主题为亮色、根画布内容完好、右上角四入口可交互。
11. **修复追溯（2026-09-21）**：色块语义修复已编译进应用。主题编辑器
    （`src\components\ThemeEditDialog.vue`）的 8 项核心颜色色块以 role=button + name 入 UI 树
    （原生 button + `aria-label=t('themes.colors.${key}')`；该对话框未使用 `ColorFieldEditor`，
    亮/暗两栏 `swatch-aria-label` 文案属节点颜色对话框，不在本用例范围）。步骤 8 的色块断言由
    aria-label 属性查找升级为 role+name 定位，并拆出「同名颜色输入框」独立断言；主题编辑器色块
    无 tooltip（源码未使用 VTooltip，实测 hover「背景」色块前后 `role=tooltip` 节点数均为 0），
    故不新增 tooltip 断言。
