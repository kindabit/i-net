# case_016 快捷键复制粘贴节点

## 测试主题

在根画布与子画布中验证 Ctrl/Cmd+C 复制选中节点、Ctrl/Cmd+V 在鼠标位置粘贴节点：单选粘贴落点与自动选中、多选相对布局保持、可重复粘贴、生效门控（对话框 / 模板面板 / 回收站面板 / 边右键菜单 / 输入框焦点）、画布数据节点过滤、跨画布粘贴归属当前画布、源节点删除后跳过不报错（逻辑删除与物理删除），以及悬浮「复制节点」按钮回归（副本仍落于视口中心）。

## 前置条件

- 复制 fixture `base` 到 `<case>\output\data` 并以该目录启动应用
- 解锁 `zz-e2e-base` / `e2e-password`，位于根画布（fixture `lastScene` 指向根画布）
- 界面语言：中文
- fixture 根画布节点：「账号 A」（约 810,432，卡片 240×120 物理像素）与「备注 B」（约 1197,700），二者之间一条无标签边
- 测试机 DPI 缩放 1.5：节点卡片 160×80 CSS = 240×120 物理像素；20 画布像素 = 30 物理像素
- 本用例新增节点与子画布均落在脚本指定的空白落点，不硬编码既有节点坐标（按 UI 树 `data-id` / `bounds` 动态定位）

## 覆盖范围

前端功能点：
- `use-node-copy-paste`：Ctrl/Cmd+C 将当前选中数据节点快照到应用内存剪贴板（影子节点与画布数据节点被过滤，过滤后为空不改变剪贴板）
- Ctrl/Cmd+V 粘贴：落点取最近指针位置（在画布容器内），包围盒中心对齐落点并逐轴按 20px 网格取整；多节点相对布局保持；粘贴后新副本自动选中；可反复粘贴
- 生效门控：无 VDialog/VMenu 打开、模板面板与回收站面板均关闭、边右键菜单关闭、焦点不在 input/textarea/contenteditable 时才生效
- 跨画布粘贴：应用内存剪贴板跨画布共享，副本归属当前画布
- 源节点已删除时跳过该节点，其余照常、无错误提示（后端对逻辑删除源返回 `NoNodeWithSuchId`，逻辑删除与物理删除均跳过）
- 回归：悬浮「复制节点」按钮副本仍落于视口中心

后端命令（经由 UI 触发）：
- `user_database_node_copy`（id + 目标画布 canvas_id + x/y：单节点、多节点、重复、跨画布；源节点逻辑删除或物理删除后返回 `NoNodeWithSuchId`，被前端静默跳过）
- `user_database_node_create`（创建子画布的画布数据节点，并作为被过滤的选择对象）
- `user_database_node_list`（画布加载与副本出现）
- `user_database_node_logical_delete`、`user_database_node_physical_delete`（S11 删除源节点）

## 备注与风险

- **选中叠层**：vue-flow 仅在框选（drag selection）后启用 `nodesselection` 叠层并遮挡选中节点；单击与 Ctrl+点击选中会把 `nodesSelectionActive` 置 false，节点仍在 UI 树中。本用例多选采用 Ctrl+点击而非框选，规避遮挡过滤。
- **UI 树不回传 vue-flow 选中态**：节点卡片不写 `aria-selected`，`states.selected` 恒为 false；选中态用截图像素断言（卡片上边框为 `--v-theme-primary` 蓝色系，沿用 case_004 的 `isSelectionBorder` 判据）。
- **节点与边的区分**：vue-flow 的节点包装元素与边包装元素都带 `role=group` 与 `data-id`；节点卡片的 `aria-roledescription` 为 `node`、边为 `edge`，卡片集合按前者过滤。
- **重叠副本被 UI 树遮挡过滤**：完全重叠的两个卡片中，被覆盖者 13 个命中采样点全部被遮挡，会从 UI 树中剔除；因此重复粘贴（S4）必须换落点，避免「节点数不变」的假象。
- **对话框 / 边右键菜单的遮罩会过滤画布**：两者打开期间画布卡片不在 UI 树中（集合为空），门控断言改为「记录打开前的卡片集合 → 关闭遮罩并静止复查 → 集合与打开前一致」。
- **落点回退分支不可经 UI 触达**：画布容器 `.canvas-view` 宽高 100%，指针恒在容器内；「鼠标不在容器内回退视口中心」分支记录为不可触达，粘贴落点的指针语义由 S2/S3/S4/S10 的「靠近鼠标点」断言覆盖（指针点与画布容器中心、窗口中心的距离均远大于判定容差）。
- **影子节点过滤分支未覆盖**：影子节点需要跨画布边构造（成本高且属 case_006/007 主题）；该过滤与画布数据节点共用同一表达式（`!data.shadowOriginId && !data.canvasRefId`），S1 覆盖画布数据节点分支，影子分支在 `coverage.md` 记录为等价未覆盖项。
- **网格取整误差**：副本左上角逐轴取整到 20 画布像素，最多偏移 10 画布像素 = 15 物理像素；落点断言容差取 60 物理像素（同时要求与视口中心距离 ≥150 物理像素以证明不是回退中心）。
- **多选相对位移误差**：两坐标分别取整，位移差最多偏差 1 画布像素 = 1.5 物理像素；断言容差取 4 物理像素。
- **复制按钮落点为画布容器中心**：实测副本落于 (≈899,681)，即画布容器（左侧留白 160 CSS 像素、顶部留白约 103 CSS 像素后的区域）中心，而非窗口中心；S12 沿用 case_004 的「窗口中心横向 ±200 / 纵向 ±250」契约，并补充「与源卡片中心距离 >150」证明不是鼠标位置语义。
- **按键注入**：Ctrl+C / Ctrl+V 用 `key_click(["Control","v"])` 同请求注入；Ctrl+点击必须在同一 `/input` 请求内 `key_press(Control)` → 移动 → 点击 → `key_release(Control)`（请求间按键不保持）。
- **门控阴性断言**：门控场景与成功粘贴场景使用完全相同的剪贴板与注入方式；S2-S4、S10 的成功粘贴作为阳性对照，门控场景「卡片集合不变」即可归因于门控生效。阴性断言用「集合相等并静止复查」的等待函数表达，不用固定 sleep 单独判定。
- **S11 无报错断言**：粘贴对 `NoNodeWithSuchId` 是 `continue` 跳过，不弹 snackbar；脚本断言 UI 树中不出现错误码文案「未找到节点」与「不允许操作画布数据节点」。
- **悬浮按钮离场残留**：hover 操作按钮前先移清场坐标并等待同名按钮消失；按钮定位须校验 bounds 位于目标卡片正上方（防误点其它卡片的同名按钮）。
- **S12 副本识别**：视口中心附近可能同时存在多个「账号 A」卡片，副本以「粘贴前后 `data-id` 集合差」识别，不用「靠近中心的卡片」这种歧义断言。
- **边右键菜单探测**：无标签边按两端连接桩中点的贝塞尔曲线取点（沿用 case_006 的几何公式与危险区过滤），带重试。
- **S8 搜索框原生粘贴**：系统剪贴板可能残留此前用例写入的文本，Ctrl+V 会把文本粘入搜索框并触发搜索下拉，属预期原生行为；脚本只断言节点卡片集合不变，随后收起搜索。

## 修订记录

1. **S8 语义定稿（2026-09-22 后端修复）**：执行阶段实测发现「逻辑删除源节点后粘贴」会复制出一个新副本（`node::service::copy` 的源查询不过滤 `deleted`，前端 `NoNodeWithSuchId` 跳过逻辑不触发），与计划不符，按流程停止并上报。后端修复后（`copy` 对已逻辑删除源返回 `NoNodeWithSuchId`）重新实测确认：逻辑删除与物理删除的源节点均被跳过、无错误提示。计划正文的 S11/F6 行文与覆盖范围据此定稿为「两种删除均跳过」；S11 步骤在原逻辑删除路径后追加永久删除路径（同一剪贴板再次 Ctrl+V），两条路径均断言卡片集合不变、无错误提示。
2. **S4 改为换落点重复粘贴**（测试设计修正）：原计划在同一鼠标位置连续 Ctrl+V；实测副本与上一次副本完全重叠时，被覆盖卡片会因遮挡过滤从 UI 树剔除，导致「节点数不变」的假象。修订为鼠标移到另一空白点 P4=(370,580) 后再次 Ctrl+V，使新旧副本互不重叠、卡片计数可靠。
3. **S5/S9 门控断言改为关闭后比对**（测试设计修正）：编辑节点对话框与边右键菜单的遮罩会把画布卡片从 UI 树过滤（打开期间卡片集合为空），原「操作前后立即比对数量」无法观测。修订为「记录打开前集合 → 按键 → 关闭遮罩并静止复查 → 集合与打开前一致」。
4. **S12 中心语义按实测修正**（测试设计修正）：复制按钮副本落于画布容器中心（实测 ≈(899,681)）而非窗口中心；S12 沿用 case_004 的窗口中心 ±200/±250 契约并补充「与源卡片中心距离 >150」以证明非鼠标落点语义；同时明确备注中「回退视口中心」的不可触达性论证。
5. **实测确认项**：S1（画布数据节点过滤 + 空剪贴板无操作）、S2（副本中心距鼠标 1 物理像素、远离视口中心 367 像素）、S3（源与副本位移差完全一致）、S10（子画布粘贴中心距鼠标 13 物理像素、返回后根画布集合不变）、S12（副本中心与窗口中心偏差 (120,77)，与源卡片距离 256）均由探针实测确认后写入断言。
