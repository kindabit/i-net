# case_001 启动与新建数据库

## 测试主题

从空数据目录启动应用，覆盖首页新建数据库的完整流程：名称步与密码步的各校验失败路径，以及创建成功、进入画布宇宙的成功路径。本用例验证「应用启动 → 首页可用 → 注册元数据 → 初始化用户数据库 → 跳转画布宇宙」主链路。

## 前置条件

- 应用以空数据目录启动：`--data-dir <case>\output\data`（目录由脚本清空重建）
- 界面语言：中文（测试机默认；脚本开始前断言首页文案为中文，若不符则先通过右上角语言菜单切换）
- 无 fixture：本用例验证从零创建，不使用共享 fixture

## 覆盖范围

前端功能点：
- 首页名称步：输入框聚焦输入、点击确认按钮、空名称校验
- 首页密码步（新建形态）：创建密码与确认密码两个输入框、空密码/短密码/两次不一致三类校验、点击返回按钮回到名称步
- Snackbar 之外的输入框内联错误提示（Vuetify error-messages）
- 创建成功后的路由跳转（画布宇宙）

后端命令（经由 UI 触发）：
- `metadata_register`（注册数据库）
- `user_database_lifecycle_initialize`（首次创建并解锁）
- `metadata_save`（异步落盘）
- `user_database_canvas_list`（画布宇宙加载根画布）
- `user_database_registry_get`（读取 lastScene，为空则进入画布宇宙）

## UI 操作流程与预期结果

| # | 操作 | 预期结果 |
|---|------|----------|
| 1 | 启动应用，等待首页就绪 | 界面出现「数据库名称」输入框与「确认」「返回」之外的基础元素；截图留档 |
| 2 | 名称留空，点击「确认」按钮 | 停留在名称步；输入框下方出现提示「数据库名称不能为空」 |
| 3 | 点击「数据库名称」输入框并输入 `zz-e2e-001`，点击「确认」 | 进入密码步；出现「创建密码」与「确认密码」两个输入框；「数据库名称」输入框消失 |
| 4 | 密码均留空，直接点击「确认」按钮 | 停留在密码步；出现提示「密码不能为空」 |
| 5 | 点击「创建密码」输入框并输入 `123`，点击「确认」 | 停留在密码步；出现提示「密码长度不能少于 6 位」 |
| 6 | 「创建密码」改为 `abc123`，「确认密码」输入 `abc124`，点击「确认」 | 停留在密码步；出现提示「两次输入的密码不一致」 |
| 7 | 点击「返回」按钮 | 回到名称步；「数据库名称」输入框重新出现，「创建密码」「确认密码」消失 |
| 8 | 重新点击「确认」进入密码步，创建密码与确认密码均输入 `abc123`，点击「确认」 | 创建成功；自动跳转画布宇宙；出现「根画布」节点文本；截图留档 |
| 9 | 检查 output\data 目录 | `metadata.sqlite` 存在；`user_database_set\` 下存在一个 uuid 目录且其中含 `user_database.sqlite` |

## 失败路径

| # | 失败场景 | 对应步骤 | 预期结果 |
|---|----------|----------|----------|
| F1 | 名称为空提交 | 2 | 提示「数据库名称不能为空」，不进入下一步 |
| F2 | 密码为空提交 | 4 | 提示「密码不能为空」，不进入数据库 |
| F3 | 密码长度不足 6 位 | 5 | 提示「密码长度不能少于 6 位」，不进入数据库 |
| F4 | 两次输入的密码不一致 | 6 | 提示「两次输入的密码不一致」，不进入数据库 |

## 备注与风险

- 「重名注册」（UserDatabaseNameAlreadyExists）在常规 UI 流程中不可触达：前端先合并已注册名称并以「打开」形态进入密码步，该错误码仅由后端在竞态下返回，故不在本用例范围。
- 创建成功后 `metadata_save` 为异步调用，脚本不对其落盘时机做时序断言，仅断言用户数据库目录文件存在。
- 面板切换有 0.22s 过渡动画，步骤间断言需等待目标元素出现后再定位坐标。
